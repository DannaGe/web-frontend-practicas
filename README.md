# Desarrollo Web: HTML, CSS y JavaScript

Prácticas de programación web: ejercicios de JavaScript, manejo de formularios
y dos proyectos con arquitectura Modelo-Vista-Controlador (MVC).
Instituto Tecnológico de Jiquilpan – Ingeniería en Sistemas Computacionales

## Contenido

### Ejercicios (`ejercicios/`)
33 ejercicios en HTML y JavaScript: alertas y escritura en el documento,
formularios, guardado de información en archivos y registro de datos de personas.

### Proyectos con MVC
`Trabajo individual`

- **`proyecto-mvc-csv-1/`** y **`proyecto-mvc-csv-2/`**: aplicaciones que
  registran personas mediante un formulario, permiten editar y cancelar,
  y guardan y cargan los datos desde archivos CSV.
  Separan el código en modelo, vista y controlador.

## Cómo probarlo
Descarga el repositorio y abre cualquier archivo `.html` en tu navegador.
Para los proyectos, abre el archivo `index.html` de cada carpeta.

## Tecnologías
HTML5 · CSS3 · JavaScript · Patrón MVC · Archivos CSV
